# WordleDeutsch — Wordle & Quordle auf Deutsch

Браузерный сайт с играми **Wordle** (1 слово, 6 попыток) и **Quordle** (4 слова одновременно, 9 попыток)
на немецком языке. Интерфейс полностью на немецком. Без сборки, без серверной части: обычный HTML/CSS/JS.

## Возможности

- Главное меню: Wordle, Quordle, продолжение текущей игры, статистика, правила.
- Стандартные правила: 5 букв; серый — буквы нет в слове, жёлтый — есть, но на другом месте,
  зелёный — на правильном месте. Повторяющиеся буквы обрабатываются как в оригинальном Wordle.
- Ввод с физической и экранной клавиатур (QWERTZ, с Ä, Ö, Ü и ß).
- **Сохранение данных** (localStorage браузера): все игры, попытки и итоги. Для каждой игры записывается,
  на какой попытке сколько слов угадано (`progress`), на какой попытке угадано каждое слово.
- Текущая игра сохраняется: после перезагрузки страницы её можно продолжить.
- **Новая игра** — новые слова: слова, которые уже выпадали, не повторяются, пока не закончится пул
  (тогда пул начинается заново).
- В конце игры — **пояснение слов** (часть речи и значения) из немецкого Wiktionary (нужен интернет).
- Статистика: количество игр, победы, серия побед, средние попытки и пошаговая история. Слова текущей партии скрыты до её завершения или отмены.

## Онлайн-версия

Сайт публикуется через GitHub Pages напрямую из ветки `main` (корень репозитория):
https://efrem199.github.io/WordleDeutsch/

## Запуск

```bash
npm start            # python3 -m http.server 8000 --bind 0.0.0.0 (из корня репозитория)
# открыть http://localhost:8000
```

Для сборки словаря и тестов нужен Node.js 22.18 или новее. Для локального HTTP-сервера нужен Python 3.

```bash
npm ci
npm test
npm run check-words
npx playwright install chromium
npm run test:browser
```

GitHub Actions запускает эти проверки при push и pull request.

## Структура

```
index.html           разметка (точка входа для GitHub Pages)
css/style.css        стили
js/logic.js          правила игры (оценка попытки, выбор слов) — без DOM, покрыто тестами
js/explain.js        разбор отрендеренных статей Wiktionary и загрузка миниатюр
js/app.js            интерфейс, сохранение, маршруты (#menu, #play, #stats, #rules)
data/answers.json    отобранные существительные для загадок
data/guesses.json    пятибуквенные слова и словоформы для попыток
tools/
  build-wordlists.mjs  сборка и проверка обоих списков
  answer_words.txt     исходный список загадок, одно слово на строку
tests/                node:test и браузерные сценарии Playwright
```

## Источники данных

- **Допустимые попытки**: `dictionary-de` 3.0.0 (Hunspell de_DE / igerman98, GPL-2.0 или GPL-3.0).
  `hunspell-reader` разворачивает словоформы, а движок Hunspell через `hunspell-asm` проверяет
  каждую пятибуквенную форму с исходным регистром. В игру попадает результат в нижнем регистре.
- **Загадки**: список обычных нарицательных существительных в словарной форме.
  Первоначальный пул опирался на FrequencyWords (hermitdave, MIT, OpenSubtitles 2016).
  Новое слово добавляется в `tools/answer_words.txt`. Сборка проверяет, что оно допустимо как попытка.
- **Пояснения**: Wiktionary, de.wiktionary.org (CC BY-SA 4.0).
- **Шрифт**: Inter (SIL Open Font License 1.1), файлы в `fonts/`, лицензия в `fonts/LICENSE-Inter.txt`.

Пересборка списков слов:

```bash
npm ci
npm run build-words
```

## Ограничения

- Допустимые попытки ограничены пятью буквами и формами, которые перечисляет генератор.
- Пояснения загружаются из немецких секций «Substantiv». Для отсылок (Jacht → Yacht) и склонений
  (Ärzte → Arzt) показываются значения и ссылка на исходную статью. При сбое Wiktionary раунд остаётся доступен.
- История хранится в браузере. На HTTPS вкладки синхронизируются через Web Locks, если браузер
  поддерживает этот API. При недоступном хранилище можно продолжить игру в текущей вкладке.
